Things I Use

Posted by Colin on Tue, Feb 18, 2025

This is a running list of software, services and items I use and recommend. The Things I use page will be updated regularly.

Apps

SetApp

SetApp is a subscription service that gives access to 240+ apps for Mac and iOS. I use a ton of apps from this service so it saves me loads over the course of the year. It’s like a buffet of apps and it is all you can eat!

Things

For task management across iOS and Mac devices. Beautiful clean design and quick task entry. Lots of scope for shortcuts to control.

NordVPN

More and more new sites are geo-blocking content. NordVPN allows me to quickly appear as though I am in another country and get to the content. It is also a must if using public Wi-Fi networks. Never trust a network you don’t control!

Podcasts

Accidental Tech Podcast

Three nerds discussing tech, Apple, programming, and loosely related matters. Hosted by Marco Arment, Casey Liss, and John Siracusa.

Websites / Services

FastMail

For my email I use FastMail. Rock solid, loads of amazing features including masked email for signing up to new sites you think might spam you. Can’t recommend it highly enough. You can get 10% off your first year by using this link

IONOS for web hosting / Virtual Private Servers

This site is hosted with IONOS. I have found their VPS (Virtual Private Server) offering to be great value, especially when it comes with Plesk Web Host edition FREE! So many tools to manage your virtual server with performance boosts, virus scanning etc. And it was all cheaper than my previous host that I had to manage via command line!
